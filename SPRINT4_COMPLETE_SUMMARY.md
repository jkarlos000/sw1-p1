## 🏗️ Architecture Overview

### Three-Tier Architecture
```
┌──────────────────────────────────────────┐
│        Angular Frontend (official-sw1p1) │
│    - flutter-export.component.*          │
│    - localStorage persistence            │
│    - Progress tracking UI                │
└────────────────────┬─────────────────────┘
                     │ HTTP REST API
                     ▼
┌──────────────────────────────────────────┐
│     Express Backend (backend-p1sw1)      │
│    - ProjectExportController             │
│    - 5 REST endpoints                    │
│    - ZIP generation                      │
└────────────────────┬─────────────────────┘
                     │ Dependency Injection
                     ▼
┌──────────────────────────────────────────┐
│        Service Layer (8 services)        │
│    ┌─────────────────────────────────┐   │
│    │  Core Generation Services (2)   │   │
│    │  - DartCodeGenerator            │   │
│    │  - LayoutGenerator              │   │
│    ├─────────────────────────────────┤   │
│    │  Advanced Features (2)          │   │
│    │  - ThemeGenerator               │   │
│    │  - Phase23Integration           │   │
│    ├─────────────────────────────────┤   │
│    │  Setup & Config (3)             │   │
│    │  - PubspecGenerator             │   │
│    │  - PlatformConfigGenerator      │   │
│    │  - SetupGuideGenerator          │   │
│    └─────────────────────────────────┘   │
└──────────────────────────────────────────┘
```

### Data Flow
```
User Input (Angular)
  ↓
Validation (ProjectExportController)
  ↓
Generate Base Code (DartCodeGenerator)
  ↓
Generate Layouts (LayoutGenerator)
  ↓
Add Advanced Features (Phase23Integration)
  ├─ Themes (ThemeGenerator)
  ├─ State Management (Phase23Integration)
  ├─ Pubspec (PubspecGenerator)
  ├─ Platform Configs (PlatformConfigGenerator)
  └─ Guides (SetupGuideGenerator)
  ↓
Create ZIP (adm-zip)
  ↓
Return Download Link (Response)
  ↓
User Downloads
```
