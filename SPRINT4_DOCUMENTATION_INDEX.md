
```
Unit Tests (existing):     npm test (already included from Phase 1)
Integration Tests:         npm run test:e2e
API Testing:              curl POST http://localhost:3000/export
```

```
5. Create PR if using branches (5 min)
```

```
Dev:       npm start (local testing)
Staging:   Deploy to staging server
Prod:      Deploy to production after testing
```

### API Endpoints (Phase 4)
| Method | Endpoint | Purpose |
|--------|----------|---------|
| POST | `/export` | Create & download project |
| POST | `/export-preview` | Preview without download |
| GET | `/download/:id` | Download existing export |
| GET | `/status/:id` | Check export status |
| DELETE | `/cleanup/:id` | Manual cleanup |
