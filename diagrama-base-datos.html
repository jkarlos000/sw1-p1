📋 Descripción del Sistema

  • usuario: Usuarios registrados en el sistema
  • sala: Espacios de trabajo colaborativos para diagramas UML
  • asistencia: Registro de participación de usuarios en salas
  • conversacion_ia: Conversaciones con IA (Claude) vinculadas a salas
  • mensaje_chat_ia: Mensajes del chat (usuario, IA o sistema)
  • snapshot_diagrama: Instantáneas del estado del diagrama en formato JSON
  • config_ia: Configuración personalizada de la IA por sala (modelo, temperatura, tokens)
  • mensaje_attachment: Archivos adjuntos multimodales (audio con transcripción e imágenes con análisis IA)

🎯 Características Principales

  • Multimodal: Soporte para audio (con transcripción automática) e imágenes (con análisis IA)
  • IA Integrada: Claude Sonnet 4.5 para análisis de diagramas UML
  • Versionado: Snapshots de diagramas vinculados a mensajes
  • Colaborativo: Múltiples usuarios en salas con control de asistencia
  • Configurable: Parámetros de IA personalizables por sala

🔑 Convenciones

  • PK: Primary Key (Clave Primaria)
  • FK: Foreign Key (Clave Foránea)
  • UK: Unique Key (Clave Única)
  • JSONB: Datos JSON binarios optimizados para PostgreSQL
